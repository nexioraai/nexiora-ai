# Site types and capabilities

> Deribfy offers three site types: showcase website, online store, and dropshipping store. Deribfy capabilities are cumulative. Every online store has everything a showcase website has. Every dropshipping store has everything an online store has.

**Scope:** all site types.

**Questions this page answers:** What kinds of sites can I create with Deribfy? What is the difference between an online store and a dropshipping store? Which features does a showcase website have? Can I change my site type? Are all features available everywhere?

## The model: three levels that stack

### Level 1 — Common to every creation

Available for **all three site types**:

- AI website generation;
- conversational or direct editing;
- 36 languages, including right-to-left script for Arabic;
- 4 visual themes, interchangeable at any time;
- private preview before publication;
- hosting included;
- Deribfy address, or a custom domain;
- sitemap, robots file, structured data and `llms.txt` file;
- visibility score on AI answer engines;
- marketing copy and visual generation;
- contact form.

### Level 2 — What stores add

Available for **the online store and the dropshipping store**. Includes all of level 1, plus:

- product pages;
- shopping cart;
- card payments;
- order management;
- shipping;
- discount codes.

### Level 3 — What dropshipping adds on top

Available for **the dropshipping store** only. Includes all of level 2, plus:

- a supplied product catalogue;
- print-on-demand products;
- automatic order hand-off to fulfilment.

## Summary table

| Capability | Showcase website | Online store | Dropshipping store |
|---|:---:|:---:|:---:|
| AI generation and editing | yes | yes | yes |
| 36 languages, 4 themes | yes | yes | yes |
| Custom domain, hosting | yes | yes | yes |
| SEO and AI visibility preparation | yes | yes | yes |
| Marketing copy and visuals | yes | yes | yes |
| Product pages, cart, payments | no | yes | yes |
| Orders, shipping, discount codes | no | yes | yes |
| Supplied product catalogue | no | no | yes |
| Print-on-demand | no | no | yes |

## One counter-intuitive point

A dropshipping store exposes **fewer** product-editing tools than an online store. This is not an arbitrary limitation: its catalogue comes from a partner, so you choose among existing products instead of creating them. On an online store you create each product yourself, which needs more tools.

## Limits

- The site type is chosen at creation and **cannot be changed afterwards**.
- A showcase website cannot sell. Selling requires creating a store.
