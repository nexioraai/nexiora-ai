# Comment ca marche : de l'idee a la mise en ligne

> Creer un site avec Deribfy suit six etapes : decrire son activite, laisser le site se generer, l'editer, le previsualiser en prive, le publier en activant l'abonnement, puis continuer a le modifier. Les six etapes sont les memes pour les trois types de site.

**Portee :** tous les types de site.

**Questions auxquelles cette page repond :** Comment creer un site avec Deribfy ? Deribfy peut-il creer mon site automatiquement ? Comment publier un site ? Le site est-il visible avant publication ? Que se passe-t-il apres publication ? Puis-je continuer a modifier mon site ? Dois-je republier apres une modification ? Que se passe-t-il si j'arrete mon abonnement ?

## 1. Decrire votre activite

Vous ecrivez, en langage courant, ce que fait votre entreprise. Deribfy pose quelques questions si un element manque.

A partir de votre description, Deribfy **propose le type de site** qui correspond. Vous pouvez choisir un autre type. Pour une boutique en dropshipping, la facon dont vous voulez etre approvisionne vous est demandee explicitement.

Un compte est necessaire des cette etape.

## 2. Generation

Deribfy cree le site : nom, accroche, secteur, titre et sous-titre d'accueil, section a propos, sections de contenu, temoignages, coordonnees, palette de couleurs et images.

Le site est redige **dans la langue que vous avez utilisee**.

## 3. Editer

Tout est modifiable immediatement. Vous pouvez demander des changements en langage courant a l'assistant, ou modifier chaque element directement.

## 4. Apercu prive

Le bouton **Voir** ouvre un apercu **visible de vous seul**. Il affiche votre site tel qu'il sera. A ce stade, votre site **n'est pas public**.

## 5. Publier

Le bouton **Publier** active votre abonnement. **Des que le paiement est confirme, votre site est en ligne** a son adresse Deribfy.

C'est l'abonnement qui met le site en ligne : tant qu'il n'est pas actif, le site reste prive et l'apercu est le seul moyen de le voir.

## 6. Continuer a modifier

Apres publication, votre site n'est pas fige. Vos modifications apparaissent immediatement en ligne. Il n'existe aucune etape de republication.

Vous editez comme avant, avec l'assistant ou directement. Il n'y a pas de bouton « republier », parce qu'il n'y a rien a republier.

## Apres la mise en ligne

- **Domaine personnalise.** Une fois le site en ligne, vous pouvez acheter un domaine via Deribfy ou connecter le votre.
- **Commandes.** Sur une boutique, les commandes arrivent dans votre espace. En dropshipping, elles sont transmises automatiquement au traitement.
- **Arret de l'abonnement.** Si l'abonnement s'arrete, le site est retire de la ligne. Son contenu n'est pas supprime.

## Limites

- Le type de site est fixe a la creation.
- L'apercu est reserve au proprietaire du site.
- La publication depend de la confirmation du paiement.
